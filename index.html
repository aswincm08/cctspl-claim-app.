Export report

Export updates the selected month in your uploaded Excel workbook template, retaining its existing worksheet layout, merged cells, column widths, and formatting as far as the browser Excel library supports. Other month sheets remain in the workbook.

The report includes employee details, daily amounts, totals, advances, and bill status. Excel formulas in the original file are replaced with calculated values for the selected month so totals display immediately.
